### Synapse 对话推理管线 (6/4 ~ 6/5)

这是两周内最大投入方向，从零搭建端到端管线：

**管线骨架 (6/4)**

- `SynapseConductor` — 管线编排骨架
- `SynapsePreRecognitionPipeline` — 识别前处理
- `SynapseThemisRecognitionStep` — Themis 意图识别步骤
- `SynapseCandidateCatalogResolver` / `SynapseCandidateCatalogStep` — 候选目录决议与加载
- 从 SigMA 加载候选目录，允许运行时覆盖
- `SynapsePlanningPlanModels` / `SynapseTaskDefinitions` — 规划模型与任务定义
- `SynapseSlotStateContracts` — slot 状态契约
- 连接默认 SynapseRuntime

**Slot 系统与上下文 (6/4)**

- `ObservationSlotReplaceResolution` — slot 替换决议
- `SynapseSlotResolutionCommitPipeline` — slot 决议提交管线
- `SynapseRuntimeSlotReadiness` — slot 就绪态推进
- `SynapseSlotStateBySession` — 按 session 持久化 slot 状态
- 支持 `context clear turns`、`slot + action combo turns`
- 回复当前上下文、从目录回复 resolver 查询
- 明确无效 slot 更新的处理

**观测目录系统 (Observation Catalog, 6/5)**

- `ObservationCatalogProjection` — 目录投影
- `SigmaObservationCatalogSource` — 从 SigMA 获取目录源
- 目录 facets 支持与 tuple 去重
- 用 observation catalog 回复 resolver 查询

**Scope 决议体系 (6/5)**

- `ObservationScopeResolutionPolicy` — 域范围决议策略
- 从 indicator domain 推断 observation task
- 从 SigMA catalog 限定 observation resolver 查询范围
- scope 未决议时返回全部 indicator
