# 初学者术语与练习指南

## 先认识五个词

| 词语 | 通俗解释 | 例子 |
|---|---|---|
| 工作表 | Excel 文件底部的一个标签页 | `原始记录`、`汇总` |
| 行 | 一条完整记录 | 某人在某天的一次学习 |
| 列 | 所有记录共有的一个属性 | 日期、主题、学习时长 |
| 公式 | 根据其他单元格自动计算的规则 | `=SUM(E2:E20)` |
| 筛选 | 暂时只显示符合条件的记录 | 只看“已完成” |

## 为什么先保留原始数据

原始数据是核对依据。直接在原表删除或改写后，很难判断改错了什么。保留 `原始记录`，把处理结果放到 `清洗后数据`，可以随时比较和回滚。

## 练习工作簿的数据含义

`assets/excel-practice-data.xlsx` 使用虚构的学习打卡记录，不需要营销、财务或运营知识。

- `记录编号`：每条记录的唯一标签。
- `日期`：学习发生的日期。
- `学习者`：虚构姓名。
- `主题`：Excel 基础、数据清洗、公式入门或图表表达。
- `学习分钟`：本次学习时长。
- `练习题数`：完成的练习数量。
- `正确率`：答对比例，以 0 到 1 的数值存储并显示为百分比。
- `状态`：已完成、进行中或未开始。
- `学习方式`：视频、文章、课堂或练习。
- `备注`：可选说明。

## 三个循序练习

### 练习 1：数据体检

1. 找出重复的记录编号。
2. 统计 `学习分钟` 和 `正确率` 的空白数量。
3. 找出不一致的 `状态` 或 `主题` 写法。
4. 用一句话说明哪些问题可以自动修复，哪些需要保留为空。

### 练习 2：清洗和公式

1. 复制原始记录到 `清洗后数据`。
2. 删除确认后的重复记录。
3. 去掉文本前后空格，并统一状态写法。
4. 新增 `是否有效`：学习分钟为空或小于 0 时显示“需检查”，否则显示“有效”。
5. 新增 `学习小时`：学习分钟除以 60。

### 练习 3：汇总和图表

1. 统计有效记录数、总学习分钟、平均正确率和完成率。
2. 按主题汇总学习分钟。
3. 创建一个主题学习时长的条形图。
4. 写两句结论：学习投入最多的主题是什么；哪一项数据质量问题最值得先处理。

## 初学者解释模板

使用以下句式，避免只堆公式：

- “我先保留原表，因为这样改错时可以恢复。”
- “这里把同一条记录的副本删除，只保留第一次出现的记录。”
- “完成率的分子是已完成记录数，分母是全部有效记录数。”
- “空白不是 0；空白表示未知，0 表示确定没有。”
- “图表使用清洗后的数据，因此修正输入后会自动更新。”
