# 零业务背景 Excel 处理

把电子表格任务拆成能看懂、能核对、能自己继续修改的小步骤。先保护原始数据，再处理、汇总和验证；不要假设用户理解业务术语、公式或数据结构。

## 开始前

1. 用一句话复述目标，例如“把学习记录清理干净，并按主题汇总学习时长”。
2. 识别输入文件、目标工作表和期望输出。没有输入文件且用户希望练习时，使用 `assets/excel-practice-data.xlsx`。
3. 只在答案确实会改变时询问问题；否则采用最简单、可逆的做法，并说明假设。
4. 对陌生词第一次出现时立即解释。需要术语或练习说明时，读取 `references/beginner-guide.md`。

## 标准工作流

### 1. 先看，不改

- 列出工作表、标题行、有效数据范围、公式、合并单元格和明显样式。
- 读取代表性记录，确认日期、数字、百分比和文本没有混成一种类型。
- 对已有工作簿先渲染查看，保留原来的布局、公式和格式。
- 用通俗语言说明结构，例如“每一行是一条学习记录，每一列描述一个属性”。

### 2. 做数据体检

检查并量化以下问题：

- 空白：哪些列缺值、缺多少。
- 重复：按记录编号或合理的字段组合判断，不只看整行文字。
- 类型：数字是否被存成文本，日期是否可排序，百分比是否为真实数值。
- 范围：负时长、超过 100% 的正确率、不可能的日期等。
- 一致性：多余空格、同义写法、大小写和标点差异。

先给出问题清单，再修复。未知值保持空白并标记；不要凭空补数。

### 3. 可逆地清洗

- 保留原始工作表，优先新增 `清洗后数据`，不要直接覆盖原表。
- 添加 `来源行号` 或保留稳定的记录编号，确保每条结果可追溯。
- 删除重复前报告判断依据和数量。
- 统一文本前展示映射关系，例如 `完成 / 已完成 / yes -> 已完成`。
- 清洗后核对：原始行数 = 保留行数 + 删除的重复行数；解释任何例外。

### 4. 用简单公式计算

- 把原始输入和假设放在清晰的单元格或表格中。
- 派生结果使用公式，不要硬编码；优先使用 `SUM`、`AVERAGE`、`COUNTIF(S)`、`SUMIF(S)`、`IF` 等易读公式。
- 跨工作表引用始终写成 `='工作表名'!A1`。
- 公式先在一行验证，再向下填充；避免整列引用和难以审计的超长公式。
- 对关键公式添加注释或在旁边写“这一步在算什么”。
- 对除数为零、空白和未知值给出明确处理，不静默把错误变成 0。

### 5. 做一个看得懂的汇总

优先输出一个紧凑的 `汇总` 工作表，包含：

- 3-5 个最重要的数字，例如记录数、总时长、平均正确率、完成率。
- 一个按主题或日期的明细小表，能追溯回清洗后的数据。
- 只在趋势、比较或构成更容易被图形解释时添加一个图表。
- 在图表标题中写清结论或单位，不使用纯装饰图表。

### 6. 验证后再交付

- 扫描 `#REF!`、`#DIV/0!`、`#VALUE!`、`#NAME?` 和 `#N/A`。
- 抽查至少一个输入、一个中间公式和一个汇总结果。
- 核对行数、总计和百分比的分母。
- 渲染所有工作表，修复文字截断、图表空白、颜色难读和重叠。
- 保证最终文件可正常打开，且用户能找到原始数据、清洗结果和汇总。

## 常见任务做法

| 用户想做什么 | 采用做法 | 用通俗语言解释 |
|---|---|---|
| 去重 | 先确定唯一编号或字段组合，再删除副本 | “同一条记录出现了两次，只保留一份” |
| 补空白 | 能从可靠字段推导才补；否则保留并标记 | “不知道就留空，不把猜测当事实” |
| 分类汇总 | 使用 `COUNTIFS` / `SUMIFS` 或清晰的汇总表 | “把同一类记录放在一起数一数、加一加” |
| 计算比例 | 分子除以分母并设置百分比格式 | “完成率 = 完成的记录数 / 全部有效记录数” |
| 做趋势图 | 用日期或有顺序的类别作横轴 | “看数值随时间怎么变化” |
| 两表匹配 | 先检查唯一键，再使用查找公式 | “用同一个编号把两张表对应起来” |

## 面向初学者的交付说明

按以下顺序说明结果：

1. **结果是什么**：先说最重要的结论。
2. **改了什么**：列出清洗、公式、汇总和图表。
3. **用户怎么继续改**：指出可编辑的输入区域和会自动更新的结果。
4. **还不确定什么**：说明缺失值、假设和未处理的异常。

避免只说“已优化”“已处理”。使用具体数量和工作表名称。

## 练习数据

使用 `assets/excel-practice-data.xlsx` 练习完整流程。先读 `使用说明`，再处理 `原始记录`；可用 `字段说明` 理解每列含义，并用 `结果参考` 核对公式和汇总思路。不要把参考结果直接复制成答案。
